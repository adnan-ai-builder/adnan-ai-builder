## طريقتي في العمل

أستخدم التطوير بمساعدة الذكاء الاصطناعي لتسريع البحث والتنفيذ
والتوثيق والاختبار. أحدد المتطلبات ونموذج البيانات، وأراجع
التعديلات المولّدة، وأتحقق من مسارات العمل المهمة، وأتحمل مسؤولية
ما أنشره.

لا أدمج ولا أنشر شيفرة لا أستطيع فهمها واختبارها وصيانتها.

## المهارات

**معرفة عملية بمساعدة الذكاء الاصطناعي:**

- واجهات Flutter وتخطيطات RTL العربية
- Supabase Auth ونماذج PostgreSQL وسياسات RLS وتكامل RPC
- تحليل متطلبات المنتجات ومسارات العمل
- الاختبار اليدوي والتحقق من التعديلات المولّدة
- التوثيق التقني باللغة العربية

**أتعلم حالياً:** Dart وSQL وGit وسير عمل GitHub والاختبارات التلقائية.
